# Climate-Context Design Cases Prototype

_Draft instructional prototype for educator review. It is not yet tested, classroom-reviewed curriculum._

This two-meeting sequence asks seventh- and eighth-grade students to use supplied fictional climate patterns when comparing building-design choices. It tests whether climate should be developed as a recurring context for the course's building-systems idea.

## Review Before Use

- All places, buildings, ratings, and model outputs are fictional instructional data. They do not describe the school or give professional building advice.
- Confirm timing, reading level, vocabulary, and print/digital formats with the intended learners before classroom use.
- Use the teacher plans as adaptable facilitation notes, not word-for-word scripts.
- Students compare supplied evidence only. They do not interpret codes, diagnose actual spaces, or recommend repairs.

## Source and Asset Status

The science background draws on the U.S. Department of Energy's [Climate Zones](https://www.energy.gov/cmei/buildings/climate-zones), which describes climate regions using temperature, precipitation, and heating-degree-day patterns. The places, maps, data tables, diagrams, and prompts in this prototype are original instructional text. No external visual assets are included.
