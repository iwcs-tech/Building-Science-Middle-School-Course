# Culminating Task Comparison: Packet Overview

_Draft Phase 1 review packet._

## Purpose

This packet helps the course developer and educator reviewers compare three possible culminating-task structures before selecting an assessment approach or drafting the nine-week map. The tasks use the same fictional learning-building scenario so reviewers can compare the kind of student reasoning each structure elicits rather than compare unrelated topics.

## Shared Fictional Context

**Learning Studio Juniper** is a fictional one-story learning space. On a warm, sunny day, the south-facing learning room becomes warmer in the afternoon. The room has windows, a ceiling supply vent, a door to a corridor, desks, and 24 fictional occupants. Students receive only the supplied diagram, weather card, model outputs, and stated design brief. They do not investigate an actual school.

## Candidate Outcomes Being Tested

The packet tests the current, unapproved outcomes in the [Systems-Model Evidence Progression](../../systems-model-evidence-progression-proposal.md):

1. Bound a system.
2. Trace an interaction.
3. Revise with evidence.
4. Compare a response using criteria, constraints, tradeoffs, and limits.

## Candidate Tasks at a Glance

| Candidate | Primary student move | Product | Best review question |
| --- | --- | --- | --- |
| 1. Explain a bounded system | Build a supported claim about an interaction. | Labeled model and explanation with a limitation. | Does the course need a common explanation task? |
| 2. Compare whole-building choices | Weigh supplied options against criteria and a constraint. | Claim-evidence-tradeoff comparison. | Should the course culminate in an evidence-based design choice? |
| 3. Revise a model with data | Use changed inputs and outputs to improve a first model. | Before-and-after model with revision note. | Is model revision the strongest final demonstration of learning? |

## Suggested Use for Review Only

1. Have educators complete or annotate each task as a learner would.
2. Use the shared rubric to identify which candidate most clearly shows the desired evidence.
3. Compare the pacing, vocabulary, accessibility, and prerequisite knowledge in the [Pacing and Review Matrix](pacing-and-review-matrix.md).
4. Decide whether to retain, combine, revise, or replace these candidates before Phase 2 mapping.

## Boundaries

These are assessment candidates, not a request for students to solve problems at their school. The tasks use supplied fictional evidence and allow qualified conclusions only. No candidate asks for a diagnosis, professional calculation, code interpretation, repair recommendation, health information, or building-system operation.
