# Air and Ventilation Systems Slide Outline

_Draft presentation content. Build an editable slide deck only if it improves teacher delivery._

Use large text, simple arrow diagrams, and descriptive alt text. Do not use color as the only distinction among planned paths, filtered paths, unknowns, and tradeoffs.

## Lesson 1: Trace Air Paths

| Slide | Purpose | Suggested content |
| --- | --- | --- |
| 1. Title | Launch the sequence. | “How can air move through a building space?” Include the driving question. |
| 2. Notice and wonder | Elicit first ideas. | Show the fictional Learning Studio Kestrel diagram without labels. Ask where air might enter, move, or leave. |
| 3. Three different ideas | Build vocabulary. | Planned ventilation, filtration, and unplanned air movement; state that they are related but not interchangeable. |
| 4. Careful model routine | Make evidence and uncertainty visible. | Boundary → arrows → evidence → label → unknown. State: “A model is a supported possibility, not proof.” |
| 5. Your task | Clarify the student product. | Trace a marked path, label the filter, identify one unknown, and explain the evidence. |

## Lesson 2: Compare Ventilation Choices

| Slide | Purpose | Suggested content |
| --- | --- | --- |
| 6. Revisit the distinctions | Connect to Lesson 1. | “What is planned? What is filtered? What is unknown?” |
| 7. Fictional design brief | Set criteria and constraint. | Outdoor-air exchange; filter path; low noise; energy budget of four model units. State that these are not real requirements. |
| 8. Plan North | Present one fictional model. | Outdoor-air-and-filter path, modeled outputs, and energy use. |
| 9. Plan South | Present the contrasting model. | Open-window path, modeled outputs, and energy use. |
| 10. Compare, do not prescribe | Support team reasoning. | Evidence table and prompt: “What does each output support? What does it leave out?” |
| 11. Make a qualified claim | Support writing and revision. | Sentence frame: “For this fictional model, I choose __ because __. A tradeoff is __. We would still need __.” |
| 12. Reusable routine | Close the prototype. | Boundary → path → evidence → distinction → comparison → tradeoff → limitation. |

## Accessibility Check Before Use

- Every diagram has descriptive alt text.
- Every label and model value is provided in text, not color alone.
- Vocabulary is visible before analysis begins.
- Slides use readable fonts and adequate contrast.
