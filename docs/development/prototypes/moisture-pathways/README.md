# Moisture Pathways Prototype

_Draft instructional prototype for educator review. It is not yet tested, classroom-reviewed curriculum._

This two-meeting sequence develops the source → path → effect explanation routine in fictional building scenarios. It is designed for seventh- and eighth-grade students in a 40-minute, laptop-supported standard classroom.

## Review Before Use

- All cases are fictional; they do not describe the school or ask students to report a building problem.
- Confirm timing, reading level, vocabulary, and print/digital formats with the intended learners before use.
- Use the teacher plans as adaptable facilitation notes, not word-for-word scripts.
- Do not collect health or symptom information, test for mold, inspect the actual school, or ask students to recommend repairs.

## Source and Asset Status

The science background draws on the U.S. Department of Energy's [Building Enclosure: Intro Moisture Flow](https://bsesc.energy.gov/energy-basics/building-enclosure-building-science-intro-moisture-flow). The fictional cases, diagrams, cards, and prompts are original instructional text. No external visual assets are included.
