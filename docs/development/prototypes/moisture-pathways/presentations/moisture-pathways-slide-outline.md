# Moisture Pathways Slide Outline

_Draft presentation content. Build an editable slide deck only if it improves teacher delivery._

Use simple source → path → effect diagrams, large text, and descriptive alt text. Do not use color as the only way to distinguish the three pathway labels.

## Lesson 1: Trace a Water Pathway

| Slide | Purpose | Suggested content |
| --- | --- | --- |
| 1. Title | Launch the sequence. | “How can water move through a building?” Include the driving question. |
| 2. Notice and wonder | Invite initial observations. | Show the three fictional cases with no labels. Ask: “What do you notice? What do you wonder?” |
| 3. Explanation routine | Give students a reusable model. | Source → path → effect, with arrows and a note: “A model is a supported possibility, not proof.” |
| 4. Three simplified pathways | Build vocabulary. | Liquid water; water carried with moving air; condensation. State: “Real buildings can involve more than one.” |
| 5. Your task | Clarify the student product. | Identify observations, draw a model, choose a label, and name one limitation. |

## Lesson 2: Defend a Moisture Explanation

| Slide | Purpose | Suggested content |
| --- | --- | --- |
| 6. Revisit the routine | Connect to Lesson 1. | “What is observed? What is inferred? What still needs evidence?” |
| 7. Evidence is not proof | Model careful claims. | Example: “Droplets are observed” versus “The droplets prove a broken window.” Ask which sentence goes beyond the evidence. |
| 8. Case-analysis directions | Set up team work. | “Choose the best simplified label, cite evidence, and name a limitation.” |
| 9. Final Case Delta | Frame the written explanation. | Display 70°F room air, 45°F window surface, droplets on the interior surface, and missing humidity/window-construction information. |
| 10. Make a careful claim | Support writing and revision. | Sentence frame: “A possible explanation is ___. The evidence is ___. One limitation is ___.” |
| 11. Reusable routine | Close the prototype. | Observed → source → path → effect → evidence → limitation. |

## Accessibility Check Before Use

- Every diagram has descriptive alt text.
- Labels and values are written in text, not color alone.
- Vocabulary is visible before the case analysis begins.
- Slides use readable fonts and adequate contrast.
