# Lesson 1 Teacher Plan: Model a Feedback Loop

_Draft facilitation notes — 40 minutes._

## Purpose

Students build a supported model of how a fictional dashboard could inform a repeated response cycle in Studio Meridian.

## Prepare

- Display the [Feedback-Loop Model](../student/lesson-01-feedback-loop-model.md) or provide copies.
- Preview the word bank: condition, signal, decision rule, response, feedback.
- Keep the fictional-model boundary visible: “We are not checking or changing our school.”

## Agenda

| Time | Teacher move | Student work |
| --- | --- | --- |
| 0–5 min | Present the fictional Studio Meridian dashboard and a notice/wonder. | Notice one pattern and ask one question. |
| 5–10 min | Model the difference between a condition and a signal using one supplied row. | Annotate the example. |
| 10–25 min | Facilitate pairs through the evidence cards and loop template. | Draw, label, and cite a feedback-loop model. |
| 25–33 min | Compare two plausible arrows; ask what evidence supports each. | Revise one arrow or label an uncertainty. |
| 33–40 min | Collect a short exit response. | Explain one loop connection and one model limit. |

## Fictional Evidence

Studio Meridian has a south-facing window, an adjustable shade in the model, and a digital dashboard. The model’s stated goal is to keep the **modeled temperature band** between 21 and 24 degrees Celsius during the class period.

| Time | Outdoor-sun card | Dashboard signal | Fictional rule | Modeled response | Next dashboard signal |
| --- | --- | --- | --- | --- | --- |
| 9:00 | Low sun | 21.4 C | If below 21 C, use the warm-response card. | No response shown. | 21.4 C |
| 10:00 | Direct sun | 24.6 C | If above 24 C, use the shade-response card. | Shade card moves to “more shade.” | 23.5 C |
| 11:00 | Cloud cover | 22.7 C | If between 21 and 24 C, keep the current response. | Shade card stays put. | 22.6 C |

The table is not a record of a real classroom, a real device, or a recommended rule.

## Facilitation Notes

- Ask, “What changed in the model?” before naming the condition.
- Ask, “What information does the rule use?” to distinguish the signal from the response.
- Treat more than one initial arrow as discussable only when it can be supported by the supplied table.
- Emphasize that the next signal is information for the next cycle, not proof of the exact cause of a temperature change.
- Do not extend the task to students’ comfort, symptoms, real room settings, or actual equipment.

## Likely Misconceptions and Responses

| Misconception | Facilitation response |
| --- | --- |
| “The shade knows the temperature.” | In this model, the dashboard signal is information; the response follows a stated rule. |
| “One temperature reading proves the system works.” | The model supplies only limited evidence. Ask what information it leaves out. |
| “We should set our classroom shade this way.” | Re-state that this is a fictional model, not a real-building recommendation. |
| “Feedback means criticism.” | Here, feedback means information about a result returning to guide a next cycle. |

## Exit Response

“Use two arrows to explain how the 10:00 modeled response could affect the next dashboard signal. Name one thing this model cannot tell us.”

## Adaptation Choices

- Provide a pre-drawn loop with blank labels.
- Read the evidence table aloud or use a screen reader-friendly text version.
- Invite students to use arrows, numbered steps, or a short spoken explanation.
