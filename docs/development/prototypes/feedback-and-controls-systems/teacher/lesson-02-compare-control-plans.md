# Lesson 2 Teacher Plan: Compare Control Plans

_Draft facilitation notes — 40 minutes._

## Purpose

Students compare two fictional response-rule plans using supplied model outputs, criteria, and constraints. They make a qualified claim rather than identify a universally correct plan.

## Prepare

- Display the [Control-Plan Comparison](../student/lesson-02-control-plan-comparison.md) or provide copies.
- Revisit the Lesson 1 boundary: fictional model only; no real-system action.
- Display the words criterion, constraint, tradeoff, and limitation.

## Agenda

| Time | Teacher move | Student work |
| --- | --- | --- |
| 0–5 min | Revisit the feedback-loop sequence with one student-friendly example. | Identify one signal and one response. |
| 5–12 min | Introduce the two fictional plans, criteria, and constraints. | Highlight what the model is designed to value. |
| 12–24 min | Model one evidence-table comparison without declaring a winner. | Complete the comparison chart with a partner. |
| 24–33 min | Facilitate a structured evidence discussion. | Draft a claim with evidence and a tradeoff. |
| 33–40 min | Collect individual final responses. | State a limitation or needed information. |

## Facilitation Notes

- Read the criteria before looking at plan results; this prevents “lowest number wins” reasoning.
- Ask students to separate a model output from an inference about that output.
- Accept different plan choices when the claim uses evidence and names a tradeoff.
- Ask, “What would we need to know before treating this model as complete?”
- Keep all language within the fictional Studio Meridian model. Do not turn the comparison into a discussion of school settings or facility changes.

## Likely Misconceptions and Responses

| Misconception | Facilitation response |
| --- | --- |
| “Plan B wins because it has more numbers.” | Return to each stated criterion and ask which evidence matters for it. |
| “A plan that saves model-energy points is always best.” | A choice must also meet other criteria and constraints; values can conflict. |
| “The model proves this plan will work anywhere.” | The table describes one invented model and leaves out many real conditions. |
| “A rule is the same as a response.” | A rule decides when to respond; a response is what the model then shows. |

## Individual Final Response

“Which fictional plan better fits the stated priorities? Make a claim, cite two pieces of evidence, name one tradeoff, and state one limitation or additional information needed. Your answer should not recommend a change to a real building.”

## Adaptation Choices

- Provide sentence frames: “I select Plan __ because…,” “A tradeoff is…,” and “This model cannot tell us….”
- Let pairs compare before writing independently.
- Reduce the table to two criteria at first, then add the third for extension.
