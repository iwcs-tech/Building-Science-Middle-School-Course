# Lesson 1 Student Page: Feedback-Loop Model

## Studio Meridian: A Fictional Model

Studio Meridian is an invented learning space. Its dashboard, numbers, rules, and responses are made up for this activity. Do not use this page to judge, change, or report anything about a real classroom or building.

### Goal in This Model

Keep the **modeled temperature band** between 21 and 24 degrees Celsius during a class period.

### Evidence Table

| Time | Outdoor-sun card | Dashboard signal | Fictional rule | Modeled response | Next dashboard signal |
| --- | --- | --- | --- | --- | --- |
| 9:00 | Low sun | 21.4 C | If below 21 C, use the warm-response card. | No response shown. | 21.4 C |
| 10:00 | Direct sun | 24.6 C | If above 24 C, use the shade-response card. | Shade card moves to “more shade.” | 23.5 C |
| 11:00 | Cloud cover | 22.7 C | If between 21 and 24 C, keep the current response. | Shade card stays put. | 22.6 C |

### Word Bank

- **condition:** something that can change
- **signal:** information sent from a monitor in a model
- **decision rule:** an if-then instruction in a model
- **response:** the modeled action that follows a rule
- **feedback:** information about the result that returns to affect the next response
