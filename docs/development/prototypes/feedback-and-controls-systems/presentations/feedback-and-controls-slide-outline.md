## Lesson 1: Model a Feedback Loop

1. **Title and boundary** — “Studio Meridian: a fictional systems model.” State that students will not inspect or operate any real system.
2. **Driving question** — “How can a building system use information about changing conditions?”
3. **Notice and wonder** — Show the three-row fictional dashboard table.
4. **Vocabulary** — Condition, signal, decision rule, response, feedback.
5. **Worked example** — Trace the 10:00 row: direct sun → 24.6 C signal → above-24 rule → shade response → 23.5 C next signal.
6. **Model directions** — Display the five-step feedback-loop routine.
7. **Evidence reminder** — “Label arrows with supplied evidence; add one question mark.”
8. **Exit response** — Explain two arrows and one model limit.

## Lesson 2: Compare Control Plans

1. **Boundary reminder** — The comparison is fictional and is not a recommendation for a real building.
2. **Reconnect the loop** — Quick signal / rule / response check.
3. **Stated priorities** — Temperature band, daylight points, model-energy limit.
4. **Plans A and B** — Display the two fictional rules and model outputs.
5. **Criteria and constraints** — Explain how each will be used in the comparison.
6. **Discussion protocol** — “Claim, evidence, tradeoff, limitation.”
7. **Model-limit prompt** — “What information would we need before this model were more complete?”
8. **Independent response** — Claim, two evidence items, tradeoff, limitation.
