# Seasonal Heat-Pump Transfer Model

_Two-meeting residential prototype for educator review. Untested; course placement and strand decisions remain open._

Students use a fictional single-family home and supplied evidence to model how an air-source heat pump moves heat in winter and summer. This is a candidate application of the approved recurring heat-flow lens, not a complete residential heat-flow launch.

- [Unit overview](unit-overview.md)
- [Lesson 1 teacher plan](teacher/lesson-01-winter.md) and [student page](student/lesson-01-winter.md)
- [Lesson 2 teacher plan](teacher/lesson-02-summer.md) and [student page](student/lesson-02-summer.md)
- [Reasoning rubric](assessments/rubric.md) and [slide outline](presentations/slide-outline.md)

All cases and numerical model values are invented. Students need not discuss their own homes or operate equipment. Review science, accessibility, pacing, and suitability before classroom use.
