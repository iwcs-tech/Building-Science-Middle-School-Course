# Heat-Transfer Reasoning: Feedback Guide

_Draft formative guide; not a selected course assessment._

| Dimension | Evidence to look for | Next-step prompt |
| --- | --- | --- |
| Seasonal model | Winter: outdoor to indoor heat; summer: indoor to outdoor heat | “Where does heat start and end in this mode?” |
| Energy input | Separately labels electricity as input to the powered system | “What powers the transfer?” |
| Explanation | Uses supplied evidence and accounts for 3 + 1 = 4 in each fictional example | “Which evidence supports your claim, and where did each unit come from?” |
| Limits | Identifies an omitted factor and avoids treating invented values as real performance | “What does this model leave out?” |

Use student diagrams, words, or oral explanations. Feedback targets the reasoning shown; partial or missing evidence identifies a teaching opportunity rather than a fixed score.
