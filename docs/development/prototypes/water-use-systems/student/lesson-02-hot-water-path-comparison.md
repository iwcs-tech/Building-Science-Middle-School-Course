# Student Page 2: Compare Two Hot-Water Paths

_These are invented numbers for a model, not measurements or promised savings in a real home._

Home Cedar's shower is the same fixture in both drawings. In each model event, the occupant turns on the hot tap and lets water flow to the drain until it feels warm enough to use. The models assume the same starting conditions and the same number of events. They give no pipe dimensions, flow rates, installation costs, or energy measurements.

| Invented layout | Modeled water sent to drain while waiting, per event |
| --- | ---: |
| Long hot-water path from heater to shower | 6 liters |
| Short hot-water path from heater to shower | 2 liters |

1. Draw each path: water heater → hot-water pipe → shower tap → drain. Show which path is longer. What stays the same in the two models?
2. How many liters go to the drain during **three** modeled events for each layout? Show multiplication.
3. How many fewer liters does the short-path model send to the drain across those three events? Show subtraction.
4. Write a claim about **this model** using the numbers as evidence. Do not claim an exact savings for any actual house.
5. Name two missing pieces of information needed before anyone could compare real installation choices. At least one should concern a tradeoff beyond the modeled waiting water.
6. Explain why the table alone cannot tell us how much energy either layout would save.
