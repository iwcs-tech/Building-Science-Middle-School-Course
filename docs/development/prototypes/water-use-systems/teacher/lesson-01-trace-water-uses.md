# Lesson 1 Teacher Plan: Trace Water Uses

_Draft prototype — 40 minutes._

## Lesson Question

> Where does water enter, get used, and leave in this fictional system?

## Learning Target

I can draw a supported model of how water may be used in a fictional building and state what I still do not know.

## Before Class

- Share or print the [Water-Use System Map student page](../student/lesson-01-water-use-system-map.md).
- Display Slides 1–5 from the [slide outline](../presentations/water-use-systems-slide-outline.md).
- Decide whether students work in pairs or groups of three.

## Materials

- Lesson 1 student page
- Pencils, annotation tools, or a shared digital board
- Optional sticky notes for evidence and unknown labels

## Timing and Facilitation

| Time | Teacher move | Student work |
| --- | --- | --- |
| 0–5 min | Display the fictional Learning Studio Wren map. Ask, “Where does water enter, get used, or leave?” Do not complete the map for students. | Notice and wonder about the map. |
| 5–10 min | Introduce input, use, output, potable water, wastewater, and evaporation. Contrast water **use** with the moisture-pathways prototype's source → path → effect routine. | Add terms to a word bank. |
| 10–18 min | Model one careful arrow: potable-water input to the handwashing sinks because the note names that use. Model an unknown label for the roof because the diagram gives no drainage information. | Identify evidence and uncertainty in the supplied map. |
| 18–28 min | Pairs complete the system map. Prompt them to label arrows only when a supplied note supports the label. | Draw and label the model. |
| 28–35 min | Compare two maps. Ask which arrows are observations, which are inferences, and which need more information. | Revise one arrow or uncertainty note. |
| 35–40 min | Exit check: state one building water use and one thing the fictional map does not show. | Submit a brief explanation. |

## Teacher Look-Fors

- Students identify a named input, at least two water uses, and a stated output.
- Students distinguish water use from water moving through a wall, roof, or other enclosure part.
- Students attach an arrow to supplied evidence rather than assuming every room has the same water use.
- Students name uncertainty instead of treating the map as a complete picture of a real building.

## Facilitation Questions

- Which note supports that arrow?
- Is this an input, a use, an output, or something the diagram does not tell us?
- How is this water-use model different from tracing rainwater or vapor through a building enclosure?
- What would we need to know before making a stronger claim?

## Safety and Context Boundary

Use the fictional Learning Studio Wren only. Do not ask students to inspect or report on actual plumbing, drains, restrooms, kitchen equipment, cooling equipment, irrigation, or suspected leaks. Do not test water, collect health information, interpret codes, recommend changes, or contact facilities staff about a class observation.

## Assessment

Review the model and exit check using the first three criteria in the [Water-Use Systems Reasoning Rubric](../assessments/water-use-systems-rubric.md).

## Adaptations

- Provide a map with the potable-water input arrow already completed.
- Read the evidence notes aloud and let students use movable text labels.
- Reduce the task to one input, one use, one output, and one unknown.
- For extension, ask students to create a second plausible output path and name the evidence that would distinguish it.
