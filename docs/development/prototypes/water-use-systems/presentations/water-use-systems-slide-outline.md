# Water-Use Systems Slide Outline

_Draft presentation content. Build an editable slide deck only if it improves teacher delivery._

Use large text, simple arrow diagrams, and descriptive alt text. Do not use color as the only distinction among inputs, uses, outputs, unknowns, and tradeoffs.

## Lesson 1: Trace Water Uses

| Slide | Purpose | Suggested content |
| --- | --- | --- |
| 1. Title | Launch the sequence. | “How can a building use water in several connected ways?” Include the driving question. |
| 2. Notice and wonder | Elicit first ideas. | Show the fictional Learning Studio Wren map without labels. Ask where water might enter, be used, or leave. |
| 3. Four model words | Build vocabulary. | Input, use, output, unknown. State that a model focuses on some parts and leaves others out. |
| 4. Different water questions | Prevent a misconception. | Contrast water **use** in a building system with moisture moving through an enclosure. Neither model tells the whole story. |
| 5. Your task | Clarify the student product. | Trace one input → use → output path, identify another use, and label one unknown with evidence. |

## Lesson 2: Compare Water-Use Models

| Slide | Purpose | Suggested content |
| --- | --- | --- |
| 6. Revisit the routine | Connect to Lesson 1. | “What is the input? What is used? What leaves? What is unknown?” |
| 7. Fictional design brief | Set criteria and constraint. | Four named uses, total-input cap, garden-use cap, and a warning not to assume identical weather or attendance. |
| 8. Model Brook | Present one fictional forecast. | Table with modeled category values and the rainy-day note. |
| 9. Model Vale | Present the contrasting forecast. | Table with modeled category values and the dry-day note. |
| 10. Compare, do not prescribe | Support evidence reasoning. | Prompt: “Which values fit the stated priorities? What does the weather note leave unresolved?” |
| 11. Make a qualified claim | Support writing and revision. | Sentence frame: “For this fictional model, I choose __ because __. A tradeoff is __. We would still need __.” |
| 12. Reusable routine | Close the prototype. | Boundary → input/use/output → evidence → distinction → comparison → tradeoff → limitation. |

## Accessibility Check Before Use

- Every map or diagram has descriptive alt text.
- Every value and label is provided in text, not color alone.
- Vocabulary is visible before analysis begins.
- Slides use readable fonts and adequate contrast.
